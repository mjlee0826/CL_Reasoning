## 4. 加權投票下真實替換的效果

- 對每個弱模型區塊（宿主 × 資料集）、確認用的菜單、供體、切分，菜單內每條 path p 做一次菜單內的替換。在評分半 ∩ 子集二上算：
  - 分子 = 替換後 WV 的得分平均 − 替換前 WV 的得分平均（規則 C）。
    - 替換前的權重用宿主 K 條 path 的選擇半答對題數算。
    - 替換後的權重：p 用供體那條在選擇半的答對題數重算，其他 K − 1 條不變。
  - 分母 = 供體那條 path 的正確率 − 宿主那條 path 的正確率（和等權投票相同）。
- 排除規則同 RQ3-GS 第 5 節：
  - 菜單內任一條 path 在這次切分不是有效切分，這個（菜單、供體、切分）整個不計，K 條 path 都不進入任何總和。
  - 排除只看單條 path 的答對題數，和聚合方式無關，所以 WV 與 V 排除的是同一批。
- 某一群的效果 = 10 × 分子總和 ÷ 分母總和。
  - 單位：那條 path 每進步 10pp，加權投票多幾個 pp。
  - 總和的範圍是該區塊內所有相關的（菜單、供體、切分）；先加總再相除。
- 若某個區塊在某項判定中沒有任何可用的（菜單、供體、切分），停下來回報，不算該判定（同 RQ3-GS 第 5 節）。
- 同一批（菜單、供體、切分）上同時算等權投票 V 的同一個量（分子換成 V 的得分，規則 C），並排報告。

## 5. 三項判定（8 個弱模型區塊，各 K 的「明顯落單」組）

- 區塊值 E_W(K) = 其他 K − 1 條在 WV 下的效果 − 落單那條在 WV 下的效果。
  - 落單那條：每次切分依第 3 節在選擇半決定。「其他 K − 1 條」：同一次切分的另外 K − 1 條。
  - 兩群各自先把分子、分母加總再相除（第 4 節）。
- 正向 = 落單那條最不值得改。
- 判定一：K = 3，62 份，門檻 **0.50**。
- 判定二：K = 5，254 份，門檻 **0.30**。
- 判定三：K = 7，254 份，門檻 **0.20**。
- 門檻和等權投票相同（RQ3-GS 的 0.5；RQ3-GSK 的 0.30、0.20），兩種投票用同一把尺。
- 四種狀態，照 RQ3-GSK 第 2 節的原文抄入，只換門檻的數值（T = 該項判定的門檻；單位是第 4 節的單位）：
  - 門檻：判定一 **0.50**、判定二 **0.30**、判定三 **0.20**。
  - 狀態有四種，都是先對區塊取平均，再和門檻比：
    - 正向成立：平均 ≥ +T，且 95% 區間不含 0。
    - 反向成立：平均 ≤ −T，且 95% 區間不含 0。
    - 兩者相當：整個 95% 區間落在 [−T, +T] 之內。
    - 無法判定：其他情況。
- 事先寫下的讀法（每個 K 各自套用）：
  - 正向成立：依正確率加權的投票下，和其他條最不像的那條仍然最不值得改。
  - 兩者相當：加權之後落單與否沒有實質差別；落單規則只適用於等權投票。
  - 反向成立：加權之後落單的那條反而比較值得改。原因看第 7 節 11：
    落單那條的效果裡，8 個區塊合計時權重的部分大於答案的部分，
    才能寫成換進來的強 path 權重變高、壓過相像的那幾條；否則只列數字。
  - 無法判定：只列數字；不能把落單規則寫成適用於加權投票。
- 三項合起來的讀法：三項都正向成立，才能寫「K = 3、5、7 的加權投票下都成立」；否則逐 K 照各自的狀態寫。
- 事先寫下的限制（論文要照寫）：
  - (a) 明顯落單組裡落單的 path 全是翻譯的語言 path，分不開「不像」「是翻譯的」「比較弱」。
  - (b) 菜單只由 12 條 path 排出來，彼此不獨立；三項判定用同一批題目與 path。
  - (c) 這些菜單上等權投票的結果已經看過，而加權投票和等權投票高度相關，所以這不是獨立的確認。
  - (d) 加權投票的權重要用標準答案（選擇半）；落單分數不用。
  - (e) 替換同時改變那條 path 的答案與它的權重，兩者沒有分開。第 7 節 11 把兩者拆開，只報告。
- 只有這三項參與判定，其餘都只報告，不套四種狀態（第 7 節 9 的對照只報狀態，不參與判定）。

     - 轉換率（真實、隨機模型），WV 與 V 並排。
