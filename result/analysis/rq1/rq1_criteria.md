## 2. 切分與 probe

- 每個資料集用 `Analysis.splitHalf.makeSplits(n, reps=200, seed=0)`，第 r 次重複得到 H1 / H2。同一資料集的所有模型和配對共用。
- 決策只能用 H1 的資訊；評估一律在該格的整個 H2 上做。
- 隨機 probe：
  - 第 r 次重複以 `numpy.random.default_rng([0, r])` 把 H1 隨機排序，每格取「在自己 both_answered 子集內」的前 k 題。
  - k ∈ {25, 50, 100, 200, 500}。k 大於該格 H1 題數時跳過並標記。
- 只抽分歧題的 probe（只報告）：
  - 用同一個排序，取前 k 題分歧題。分歧題 = 兩條 path 的答案不同。
  - 不足 k 題時用全部，並標記。

## 3. 方法（皆為 H2 上的正確率）

- s(I)：在題目集合 I 上，配對兩條 path 中正確率較高的一條。平手時用固定順序：L:en 優先，其餘依 path 代號的字母序。
- Excess(I) = acc_聚合(I) − acc_s(I)，等於 d·(c−m)·(recovery − recovery_blind)。
- 三種做法：
  - **我們的決策 D**：Excess(來源) > 0 就聚合，否則用 s(來源)。Excess = 0（包含來源裡沒有分歧題）判為不聚合。
  - **永遠聚合 A**。
  - **永遠用單一 path S**：用和 D 相同的 path s(來源)。
- Oracle O = max(acc_聚合(H2), acc_a(H2), acc_b(H2))；regret_X = O − acc_X(H2)。
- 「來源」在各設定中的意思：

| 設定 | 來源 | s 怎麼選 |
|---|---|---|
| 同格 probe | 同一格 H1 中的 k 題 | 在這 k 題上選 |
| 換模型 | 同資料集、同配對、同聚合器、另一個模型，用它的整個 H1 | 來源 H1 上較強那條 path 的同名 path |
| 換資料集 | 同模型、同配對、同聚合器、另一個資料集，用來源資料集第 r 次的 H1；目標用目標資料集第 r 次的 H2 | 同上 |
| 換多樣性來源 | 同模型、同資料集、同聚合器，**另一軸**的配對，用整個 H1 | 目標配對的兩條 path 在 H1 上較強者 |

- 遷移時，每個目標格對每個可用的來源各算一次，再對來源平均。遷移不涉及 k。

## 4. 區塊與統計

- 區塊 = 模型 × 資料集。
- 區塊值 = 對該區塊內所有 Judge 格（遷移時是所有目標格 × 來源）和 200 次重複取平均。
- 跨區塊：平均值、SE = sd / √B，95% 區間 = 平均 ± t(0.975, B−1) · SE，B 是區塊數。

## 5. 判定

對每個設定 X（同格隨機 probe 的 k = 200，以及三種遷移各自）：

- regret_A(X)、regret_S(X) 都是跨區塊平均。
- 空間(X) = min(regret_A(X), regret_S(X))。
- 較好的笨方法 B(X) = 兩者中跨區塊平均 regret 較小的那個。
- 每個區塊的差距 = acc_D − acc_B(X)（H2 上），然後算跨區塊平均和 95% 區間。
- **X 達標**：平均差距 ≥ 0.5 × 空間(X)，且 95% 區間的下界 > 0。

判定：

1. **沒有空間**：同格 k = 200 時，空間 < 0.2 個百分點 → RQ1 只當附錄。
2. **成功**：同格 k = 200 達標，**而且**至少一種遷移設定達標。換多樣性來源只算不同軸的來源。
3. 其他情況：不成功。同格 probe 只能用來否決，不能單獨當作成功的證據。

以上門檻（0.2pp、0.5 × 空間、95%、k = 200）是暫定值，使用者確認後填入確認時間。
