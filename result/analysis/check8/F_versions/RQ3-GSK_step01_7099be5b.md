## 3. 把落單程度推廣到 K 條（只看答案是否相同，不用正確答案）

- 兩條 path 的一致率：同 RQ3-GS 第 4 節（規格寫「第 3 節」，指的是一致率的定義所在的那一節）。
- 菜單裡每條 path i 的分數：
  - s_i = 其他 K − 1 條彼此的一致率平均 − i 和其他 K − 1 條的一致率平均。
  - 「彼此的一致率平均」是其他 K − 1 條兩兩組合的 C(K−1, 2) 個一致率的平均；「i 和其他條」是 K − 1 個一致率的平均。
- 落單的 path = s_i 最大的那條；落單程度 = 最大的 s_i。最不落單的 path = s_i 最小的那條。
- **【補充，待確認】平手規則**：s_i 由大到小排名，相同時平手順序**在後**的排前面。所以：
  - 落單的 path = 第 1 名：最大的 s_i 相同時，取平手順序在後的那條；
  - 最不落單的 path = 第 K 名：最小的 s_i 相同時，取平手順序在前的那條；
  - 第 8 節 2 的名次也用這個排序。
  - 理由：
    - K = 3 時，s_i 相同等於「一致率最高的一對」有兩對以上相同。RQ3-GS 的規則是取字典序在前的那一對。逐一檢查三種平手的情況，它都等於「在相同的 s_i 裡取平手順序在後的那條」當落單的 path。
    - 規格寫的「相同時依平手順序」若解讀成取在前的那條，K = 3 時會和 RQ3-GS 不同。
    - 第零階段：K = 3 的 62 份明顯落單菜單 × 8 個區塊 × 200 次切分中，有 193 次在選擇半出現這種平手（附錄 A.2）。所以第 9 節 1「逐區塊差 ≤ 1e-9」只有在這個規則下才可能通過。
- K = 3 時這和 RQ3-GS 的定義完全相同：
  - 設 T = 三組一致率的和，i 以外那一對的一致率是 r_jk，則 s_i = r_jk − (T − r_jk) / 2 = 1.5 × r_jk − T / 2。
  - 所以 s_i 最大的 path，就是一致率最高那一對以外的那條；最大的 s_i = 最高的一致率 − 另外兩組的平均。
  - 第 9 節 2 檢查。
- 分組用的 s_i：
  - 8 個弱模型區塊、子集一的全部題目，各區塊算完再平均。
  - s_i 是一致率的線性組合，所以這等於用 8 個區塊平均的一致率來算。
- 判定時的落單 path：每個區塊、每次切分，在該區塊選擇半 ∩ 子集一的題目上重算（同 RQ3-GS 判定二）。
  - 用整數題數精確比較：a_jk = 選擇半 ∩ 子集一中 j、k 答案相同的題數。
  - 比較 S_i = (K − 1) × Σ（其他條兩兩的 a）− C(K−1, 2) × Σ_j a_ij。
  - S_i 和 s_i 只差一個所有 path 共用的正數倍數，所以排序相同。
  - 這裡的落單 path 可以和菜單表的不同；組別仍用菜單表。

## 5. 真實替換的效果怎麼算

- 對每個弱模型區塊（宿主 × 資料集）、確認用的菜單、供體、切分，菜單內每條 path p 做一次菜單內的替換。在評分半 ∩ 子集二上算：
  - 分子 = 替換後 V 的得分平均 − 替換前 V 的得分平均（規則 C）。
  - 分母 = 供體那條 path 的正確率 − 宿主那條 path 的正確率。
- 排除：菜單內 K 條 path 中任一條在這次切分不是有效切分，這個（菜單、供體、切分）整個不計，K 條 path 都不進入任何總和。
- 某一群 path 的效果 = 10 × 這一群的分子總和 ÷ 分母總和。
  - 單位是「那條 path 每進步 10 個百分點，投票多幾個百分點」。
  - 總和的範圍是該區塊內所有相關的（菜單、供體、切分）。先加總再相除。
- 若某個區塊在某項判定中沒有任何可用的（菜單、供體、切分），停下來回報，不算該判定。
- 第零階段的排除比例（附錄 A.4）：只有 gpt4omini × commonsenseqa 配 DeepSeek 明顯被排除。
  - K = 5 時 34%（明顯落單組 36%），K = 7 時 43%（明顯落單組 46%）。
  - 原因是 CommonsenseQA 上 DeepSeek 只比 GPT-4o mini 好一點，K 越大越容易有一條 path 不是有效切分。
  - 該區塊兩個供體合計，明顯落單組被排除 18%（K = 5）與 23%（K = 7）；其餘區塊都在 0.2% 以下。

## 6. 兩項判定（8 個弱模型區塊，各自的「明顯落單」組；K = 5、K = 7 各一項）

- 區塊值 E_K = 其他 K − 1 條的效果 − 落單那條的效果。
  - 落單那條：每次切分依第 3 節在選擇半決定。
  - 「其他 K − 1 條」：同一次切分的另外 K − 1 條。
  - 兩群各自先把分子、分母加總再相除（第 5 節），單位同 RQ3-GS。
- 正向 = 其他條比落單那條有效（落單那條最不值得改）。
- 判定一：K = 5，254 份明顯落單的菜單，門檻 **0.30**。
- 判定二：K = 7，254 份明顯落單的菜單，門檻 **0.20**。
  - 門檻 = 0.5 × 3 ÷ K，取到 0.05。
  - 理由：投票的轉換率大約是 1 / K，同樣的相對差距在 K 變大時絕對值會變小。沿用 0.5 的話，「兩者相當」會太容易成立。
  - 四種狀態的定義不變（第 2 節），只把 0.5 換成這兩個值。
- 事先寫下的讀法：
  - 正向成立：K 條 path 投票時，和其他條最不像的那條仍然最不值得改。
  - 兩者相當：K 條時落單與否沒有實質差別；K = 3 的規則不能推廣。
  - 反向成立：K 條時落單的那條反而比較值得改。
  - 無法判定：只列數字；不能把 K = 3 的規則寫成適用於更大的 K。
- 事先寫下的限制：
  - (a) 明顯落單組裡落單的 path 全是翻譯的語言 path（K = 5：JA 125、ZH 64、RU 54、ES 11；K = 7：JA 187、ZH 37、RU 29、ES 1）。所以這兩項判定分不開「不像」「是翻譯的」「比較弱」。
    - 正向成立時，論文只能寫「K 條 path 投票時，和其他條最不像的那條翻譯的 path 最不值得改」。
    - 要去掉「翻譯的」，還要看第 8 節 4。K = 7 的 4(a) 只有 8 份菜單、而且都在對稱組，所以 K = 7 大概分不開。
  - (b) 菜單只由 12 條 path 排出來，彼此不獨立。
  - (c) 兩項判定用同一批題目與 path，不是兩次獨立的確認。

只有這兩項參與判定，其餘都只報告，不套四種狀態（第 8 節 10 的對照除外，它只報狀態，不參與判定）。

     - 「正確率最低」= 選擇半 ∩ 子集一答對題數最少的那條，相同時平手順序在前，同 RQ3-GS。
   - (c) 範圍是明顯落單組，只用正確率最低的那條不是落單 path 的（菜單、供體、切分），算「其他條的效果 − 正確率最低那條的效果」。
   - (b)、(c) 都報用到的（菜單、供體、切分）比例。
5. 模擬這一側（16 個區塊，子集一，規則 C）：
   - 比值 = 落單的 path 的 π ÷ 其他 K − 1 條 π 的平均。
   - π 在評分半上算；落單的 path 依第 3 節在選擇半決定。
   - 分子、分母各自先對切分、菜單、16 個區塊平均，再相除，同 RQ3-GS §9.6。
   - 在全部 762 份與明顯落單組各報一次。
6. 兩項判定在規則 A 下的值：分子用規則 A 的得分；落單的 path 不變，因為它只看答案。
7. RQ3-GK 既有的菜單（K5-01 到 K5-30、K7-01 到 K7-30）當作對照：
   - 用第 4 節的門檻分組；
   - 報各組（明顯落單、中間、對稱）與全部 30 份的 E_K。
8. 不除以分母的版本（明顯落單組，兩群：其他條、落單那條）：
   - 投票實際多幾個百分點 = 100 × 分子總和 ÷ 替換數。
   - 那條 path 實際進步幾個百分點 = 100 × 分母總和 ÷ 替換數。
   - 逐區塊算，報 8 個區塊的平均與 95% t 區間。
9. 各區塊自己算出的落單 path：
   - 用該區塊子集一的全部題目，第 3 節的算法。
   - 報它和菜單表（8 個區塊合起來算）的落單 path 相同的（區塊、菜單）比例。
   - K = 3 用 RQ3-GS 的 187 份，K = 5、K = 7 用各自的 762 份。逐區塊列出，並報平均。
10. 門檻改用 0.5 時，兩項判定的狀態（對照）。
11. 落單那條的效果 ÷ 其他條的效果：
    - 逐區塊算，報 8 個值、中位數與範圍。
    - K = 3 也算一次當對照：用 RQ3-GS 明顯落單組的 `rq3gs_blocks.csv` 的 `E2_lone_effect` ÷ `E2_pair_effect`。
