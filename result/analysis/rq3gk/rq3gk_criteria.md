## 1. 目的

這是診斷用的分析。跨模型替換只用來製造真實的改進，不是推薦的系統。要回答三件事：

1. K 小到 3 時，換進一條強的 path 之後，投票是不是仍然輸給直接用最強的那一條？（判定一）
2. K = 3 時，用一半題目挑得出比較值得改進的 path 嗎？（判定二）
3. 描述：各個量怎麼隨 K 變化。（只報告）

## 4. 平手規則

每一題的「得分」s_i 在 0 到 1 之間；V 的正確率 = 得分的平均。

- 規則 A（原本的）：最高票平手時，依平手順序找第一條答案落在平手答案中的 path，取它的答案。答對得 1，答錯得 0。這就是 RQ3-G 的 V。
- 規則 B（反過來）：同規則 A，但平手順序反過來：ZH、W2、W1、S2、S1、RU、R、P2、P1、JA、ES、EN。只用在第 9 節 4 的核對。
- 規則 C（平分）：最高票平手時，正確答案在平手的答案中，得 1 ÷ 平手的答案數，否則得 0。沒有平手時，得分 = 規則 A 的對錯。
- 每個規則下，π、gain、D1、隨機改進模型的期望值都照該規則的得分算：
  - π_p = p 答錯的題目中，把 p 改對後該題得分的平均增加量。
  - 期望值公式與 RQ3-G §4 相同，只是把「聚合是否答對」換成「該題得分」。
  - 不論哪個規則，把 p 改對都不會讓該題得分下降。程式逐題核對，不符就停。
- 精確比較：得分乘上 27720（1 到 12 的最小公倍數）後是整數，所以 p\* 與「相同 gain」的判斷都用整數或有理數比較，沒有浮點誤差。
- 其他平手：
  - WV 在規則 C 下也照平分算：加權分數在最高分 1e-9 以內的答案都算平手，得分 = 正確答案在其中時 1 ÷ 平手的答案數。規則 B 下 WV 用反過來的順序。
  - SB 的選擇（選擇半答對題數最多）在三種規則下都用原本的平手順序。SB 不是投票，不受規則 C 影響。
  - p\* 的平手：規則 A 與規則 C 用原本的平手順序，規則 B 用反過來的順序。

## 5. 區塊值的算法

- 每個 K：先算每份菜單的值（算法同 RQ3-G），再對該 K 的菜單等權平均，得到區塊在該 K 的值。
- 替換的量（8 個弱模型區塊）：
  1. 每個替換：有效切分的平均。
  2. 每份菜單：菜單內參與判定的替換（菜單內的 path × 2 個供體）的平均。
  3. 每個 K：該 K 的菜單的平均。
  - 某份菜單在某個區塊沒有任何替換參與判定時，這份菜單不納入該區塊的平均，並報次數。
  - 判定一中，若某個區塊在 K = 3 沒有任何一份菜單有參與判定的替換，就停下來回報，不算判定一。
- 轉換率：區塊在該 K 的值 = 該 K 所有菜單、所有參與判定的替換，分子的總和 ÷ 分母的總和。分子、分母都是有效切分的平均（同 RQ3-G §8.6）。
- 統計單位是區塊。報平均、SE（= 標準差 / √區塊數）、95% t 區間（自由度 = 區塊數 − 1）、幾個區塊為正。計算用 `Analysis.blockStats.summarize`。

## 6. 判定一：K = 3 時，替換後投票還輸給最強單一嗎（8 個弱模型區塊，規則 A，子集二）

- 每份 K = 3 的菜單、菜單內每條 path、每個供體做一次替換，共 30 × 3 × 2 = 180 個。
- E1 = 100 × (替換後 V 的正確率 − 替換後 SB 的正確率)，在評分半上算，單位 pp。
  - SB 在替換後的菜單內重新選：用選擇半的答對題數，被換進來的那條用供體的答對題數。
- 區塊值：先對每個替換取有效切分的平均，再對菜單內參與判定的替換平均，再對 30 份菜單平均。
- 正向 = 投票較高。
- 事先寫下的讀法（論文會怎麼寫）：
  - 反向成立（投票較低）：K 小到 3，等權投票仍用不到明顯領先的 path；12 條時吃不到，不只是因為 K 太大。
  - 兩者相當：K = 3 時投票和最強單一打平；K 夠小可以補回差距。
  - 正向成立（投票較高）：K = 3 時投票勝過最強單一；12 條時的落差主要是 K 太大，主軸要加上 K 這個條件。
  - 無法判定：只列數字。

## 7. 判定二：K = 3 時挑得出比較值得改的 path 嗎（16 個區塊，規則 C，子集一）

- 用規則 C，是因為這一項問的是 path 本身的差別，不能讓平手順序偏袒任何一條。
- 每份 K = 3 的菜單、每次切分：
  - 在選擇半算 3 條的 gain（規則 C 的得分，提高 5 個百分點），選最大的 p\*。精確比較；相同時依平手順序。
  - 在評分半算 D1 = gain(p\*) − 其餘 2 條 gain 的平均。
- 區塊值 = 200 次切分與 30 份菜單的平均。
- 正向 = 選擇半挑出來的 path，在評分半上的 gain 比其他 path 大。
- 事先寫下的讀法：
  - 正向成立：K = 3 時，用一半題目挑得出比較值得改的 path（提高 5 個百分點時多 0.5pp 以上）。
  - 兩者相當：連 K = 3 都挑不出實質的差別。
  - 反向成立：挑出來的反而較差，排名不穩定。
  - 無法判定：只列數字。

- 判定一有 8 個區塊，判定二有 16 個。計算用 `Analysis.blockStats.summarize`，狀態用 `Analysis.blockStats.fourState`，與 RQ3-G 相同。
- 以下照 RQ3-G 判定標準檔（`result/analysis/rq3g/rq3g_criteria.md` §7）原文抄入：
  - 門檻：**0.5pp**（暫定值，確認本檔時一併確認）。
  - 狀態有四種，都是先對區塊取平均，再和門檻比：
    - 正向成立：平均 ≥ +0.5pp，且 95% 區間不含 0。
    - 反向成立：平均 ≤ −0.5pp，且 95% 區間不含 0。
    - 兩者相當：整個 95% 區間落在 [−0.5, +0.5] 之內。
    - 無法判定：其他情況。
- 只有判定一、判定二參與判定。其餘都只報告，不套四種狀態。

## 9. 只報告的量（不參與判定）

除非另外註明，以下規則都適用：
- 每個 K 都算，區塊值依第 5 節。
- 跨區塊報平均與 95% t 區間（`summarize`），只描述。
- 替換的量只用有效切分與參與判定的替換。

1. 每個 K 的曲線（規則 A；另列規則 C）：
   - 16 個區塊（子集一，沒有替換）：
     - π 的平均、gain 的平均：先對菜單內的 path 平均，再對菜單平均。π 無定義的切分不納入。
     - D1、V、SB、V − SB。
   - 8 個弱模型區塊（子集二）：
     - 那條 path 增加的正確率（供體 − 宿主，評分半）、V 增加的正確率（A_real − 替換前的 V）。
     - 轉換率（真實與隨機模型）、D2。
     - 替換後的 V − SB、替換後的 WV − SB。
   - SB 與「那條 path 增加的正確率」不受平手規則影響，兩種規則下相同。
2. 獨立假設下的對照（8 個弱模型區塊，子集二，評分半）：
   - 把菜單內每條 path 當成彼此獨立、各自以它在評分半的正確率答對，算「答對的 path 數至少 ⌊K/2⌋ + 1」的機率（Poisson-binomial）。K 為奇數時就是超過 K 的一半；K = 12 是至少 7 條。
   - 替換前用宿主各條的正確率；替換後把 p 換成供體那條的正確率。
   - 每個 K 報替換前與替換後的值，和實際的 V（規則 A 與規則 C）並列。
   - 獨立假設的轉換率 = 該 K 所有菜單、所有參與判定的替換，「替換後 − 替換前」的總和 ÷ 「那條 path 增加的正確率」的總和。
3. 最高票平手的題目比例（16 個區塊，子集一，評分半，沒有替換）：
   - 最高票數由兩個以上的答案共有的題目所占的比例。
   - 每個 K 報一次。
4. 平手規則的核對（事後分析，取代核對五）：
   - M12 與 M3S，規則 A、B、C 各算一次（16 個區塊，子集一）：
     - 每條 path 的 π（評分半），16 個區塊的平均。
     - p\* 落在各條的比例（判定二的做法），16 個區塊的平均。
   - 比值 = 16 個區塊平均的 EN 的 π ÷ 16 個區塊平均的 (S1 的 π + S2 的 π) / 2。
   - 事先寫下的讀法（看規則 C，M12 與 M3S 都要符合）：
     - 兩份菜單的比值都在 0.8 到 1.25 之間：EN 的高影響力來自平手規則。
     - 兩份菜單的比值都在 1.5 以上：平手規則解釋不了，只回報。
     - 其他情況：只回報。
   - 另外每個 K 報：規則 A 與規則 C 下，菜單內平手順序第一的 path 的 π ÷ 其餘 path 的 π 的平均。
     - 分子、分母各自先對 16 個區塊與該 K 的菜單平均，再相除。
5. 和簡單做法比（K = 3 與 K = 12，規則 C，子集一）：
   - 把判定二的 p\* 換成下列三種 path，各算一次 D1，報 16 個區塊的平均、95% t 區間與為正的區塊數：
     - 選擇半正確率最高的那條。
     - 選擇半正確率最低的那條。
     - 平手順序第一的那條。
   - 正確率相同時，「最高」與「最低」都取平手順序中較前的那條。
   - 另外報：判定二的 p\* 與這三種 path 相同的切分比例（三者可以重疊），以及選擇半出現相同 gain（最大的 gain 由兩條以上共有）的切分比例。
6. 每個 K：弱模型區塊內，預測增加量（選擇半）與實際增加量（評分半）的 Spearman 相關。
   - 算法同 RQ3-G §8.7，用規則 A。
   - 替換的範圍是該 K 所有菜單的替換。每次切分對其中參與判定、且該次切分有效的替換算一次。
   - 報 8 個區塊的值、它們的平均，以及無定義的切分數。
7. 其他 K 的判定量：
   - 判定一的量（E1，規則 A）在 K = 5、7、9、11、12 的值。
   - 判定二的量（D1，規則 C）在 K = 5、7、9、11、12 的值，以及規則 A 下在所有 K 的值。
8. 領先幅度（8 個弱模型區塊，子集二，規則 A；每個 K）：
   - 領先幅度 = 選擇半上，替換後那條 path 的正確率 − 菜單內其餘 path 中最高者（pp）。
   - 逐替換存進 rq3gk_substitutions.csv（有效切分的平均）。
   - 每個 K 報：領先幅度的區塊平均；領先幅度 > 0 的替換比例；每個區塊內「領先幅度」與「替換後的 V − SB」的 Spearman 相關，再對區塊平均。算法同 RQ3-G §8.8，替換的範圍是該 K 所有菜單中參與判定的替換。

## 10. 開跑前的檢查

依序做，任何一項不過就停下來回報，不寫輸出。RQ3-G 載入時的核對（題目 id 與 gold、`compareTwoAnswer`、整數投票 = `vote`）照做，不符也停。

   - D1 +0.23pp（+0.17 到 +0.30），16 / 16 為正。
   - D2 +0.23pp（+0.13 到 +0.33），8 / 8 為正。
   - 轉換率：真實 0.077、隨機模型 0.053（8 個區塊的平均）。
   - 以上四捨五入後要相同；逐區塊和 `result/analysis/rq3g/rq3g_cells.csv`（M12、path = `ALL` 的列：`D1_pp`、`D2_pp`、`conversion_real`、`conversion_sim`）的差都要 ≤ 1e-9。
2. 用這次「任意菜單」的程式重現 RQ3-G 的 M3L、M3S、M3P：
   - D1 是 +0.82、+0.59、+0.51；D2 是 +0.55、+0.64、+0.54，四捨五入後要相同。
   - 逐區塊和 `rq3g_cells.csv` 對應菜單 `ALL` 列的 `D1_pp`、`D2_pp` 的差都要 ≤ 1e-9。
3. 規則 C：
   - 所有區塊、所有菜單（各 K 的菜單與 M3L、M3S、M3P），子集一中沒有平手的題目上，規則 C 的得分 = 規則 A 的對錯。

     - 用一般的計分函式（不經期望值的算法）算評分半上規則 C 的 V；這一次的值 = 200 次切分的平均。
     - |2,000 次的平均 − 期望值| ≤ 3 × 蒙地卡羅標準誤（= 2,000 個值的標準差 / √2000）。
     - 2,000 個值完全相同時標準誤 = 0，這時差要 ≤ 1e-9。
