## 5. 真實替換的效果怎麼算

- 對每個弱模型區塊（宿主 × 資料集）、確認用的菜單、供體、切分，菜單內每條 path p 做一次菜單內的替換。在評分半 ∩ 子集二上算：
  - 分子 = 替換後 V 的得分平均 − 替換前 V 的得分平均（規則 C）。
  - 分母 = 供體那條 path 的正確率 − 宿主那條 path 的正確率。
- 排除：只要菜單內有任一條 path 在這次切分不是有效切分，這個（菜單、供體、切分）整個不計，三條 path 都不進入任何總和。逐區塊報被排除的比例。
- 某一群 path 的效果 = 10 × 這一群的分子總和 ÷ 分母總和。
  - 單位是「那條 path 每進步 10 個百分點，投票多幾個百分點」。
  - 總和的範圍是該區塊內所有相關的（菜單、供體、切分）。先加總再相除，不先除再平均。
- 若某個區塊在某項判定中沒有任何可用的（菜單、供體、切分），停下來回報，不算該判定。

## 6. 判定一：挑出來的那條，真的改進時比較有效嗎（8 個弱模型區塊，187 份確認用的菜單，規則 C）

- 每份菜單、每次切分：在選擇半 ∩ 子集一（宿主的區塊）上，用規則 C 的 gain（提高 5 個百分點）挑出 p\*。
  - 精確比較（整數交叉相乘）；相同時依平手順序，和 RQ3-GK 判定二相同。
  - p\* 與供體無關，兩個供體用同一個 p\*。
- 「挑出的」這一群 = 每次切分的 p\*；「其他的」這一群 = 同一次切分的另外兩條。
- 區塊值 E1 = 挑出的效果 − 其他的效果（第 5 節的單位）。
- 正向 = 挑出的比較有效。
- 事先寫下的讀法（論文會怎麼寫）：
  - 正向成立：在沒看過的組合上，挑法挑出的 path 真的改進時比其他條有效；K = 3 時挑法有效。
  - 兩者相當：挑出的和其他條差不到 0.5；事後看到的差別沒有重現。
  - 反向成立：挑出的反而較差。
  - 無法判定：只列數字；事後分析看到的差別不能寫成結論。

## 7. 判定二：最不像的那一條，真的改進時最沒效嗎（8 個弱模型區塊，「明顯落單」組 62 份，規則 C）

- 每份菜單、每次切分：在該區塊的選擇半 ∩ 子集一上，用第 4 節的算法找出落單的 path。
  - 一致率用整數題數比較；最高的有兩對以上相同時，取字典序在前的那一對。
  - 這裡的落單 path 由每個區塊、每次切分各自決定，可以和第 4 節表中的落單 path 不同。組別仍用第 4 節的表。
- 區塊值 E2 = 相像那一對（兩條合在一群）的效果 − 落單那條的效果（第 5 節的單位）。
- 正向 = 相像那一對比落單那條有效。
- 限制：「明顯落單」組的落單 path 全部是翻譯的語言 path（JA、RU、ZH、ES）。所以這項判定分不開「和其他條不像」「是翻譯的」「正確率較低」三種原因。正向成立時，論文只能寫「和兩條相像的 path 放在一起時，那條翻譯的 path 最不值得改」；要寫成「最不像的那條最不值得改」，還要看第 9 節 5 與 11 的結果。
- 事先寫下的讀法：
  - 正向成立：最不像的那條最不值得改，在沒看過的組合上成立。
  - 兩者相當：落單與否沒有實質差別。
  - 反向成立：落單的那條反而比較值得改。
  - 無法判定：只列數字。

- 以下照 RQ3-GK 判定標準檔（§8，即 RQ3-G §7 的原文）抄入：

  - 狀態有四種，都是先對區塊取平均，再和門檻比：

    - 反向成立：平均 ≤ −0.5pp，且 95% 區間不含 0。

- 只有判定一、判定二參與判定。其餘都只報告，不套四種狀態。

## 9. 只報告的量（不參與判定）

除非另外註明：8 個弱模型區塊、規則 C、第 5 節的效果與排除規則、187 份確認用的菜單；跨區塊報平均與 95% t 區間。

1. 分組：
   - E1 在三組（明顯落單、中間、對稱）各算一次。
   - E2 在中間組、對稱組、全部 187 份各算一次。
2. 命中率：
   - 每個（菜單、供體、切分），菜單內每條 path 的真實效果 = 它的分子 ÷ 分母（評分半；整數交叉相乘精確比較）。
   - 命中 = p\* 剛好是真實效果最高那條；最高的有 m 條相同時，p\* 在其中算 1/m 次命中（亂挑的期望是 33.3%）。
   - 同樣算 p\* 剛好是真實效果最低那條的比例。
   - 逐區塊列出，報 8 個區塊的平均。
   - 註：逐切分的真實效果雜訊較大，這個命中率不能和事後分析的 53% 直接比；可比的是第 4 項。
3. 換一種挑法各算一次 E1（挑出的效果 − 其他兩條的效果）。都在選擇半 ∩ 子集一上決定，相同時依平手順序：
   - 選擇半正確率最高的那條；
   - 選擇半正確率最低的那條；
   - 落單的 path（第 7 節的算法）；
   - 相像那一對中平手順序在前的那條。
4. 用其他區塊的分數來挑：
   - p\* 改用「其他 15 個區塊在這份菜單上 π 的平均」最高的那條。
   - 每個區塊的 π 用規則 C、子集一的全部題目（不切分）。16 個區塊含強模型，扣掉自己就是 15 個。
   - 這個 p\* 對每個（區塊、菜單）固定，與切分無關。重算 E1 與命中率。
   - 這一項的命中率在（區塊、菜單）層級算：
     - 每條 path 的真實效果 = 該區塊、該菜單內，兩個供體與所有可用切分的分子總和 ÷ 分母總和。
     - 命中 = 固定的 p\* 剛好是真實效果最高的那條；同樣算剛好是最低那條的比例。
     - 最高（或最低）的有 m 條相同時，算法同第 2 項（p\* 在其中算 1/m 次）。
5. 分開「不像」和「比較弱」（範圍都是「明顯落單」組）：
   - (a) 只用落單的 path 不是選擇半正確率最低那條的（菜單、供體、切分），重算 E2。
   - (b) 只用正確率最低的那條不是落單的 path 的（菜單、供體、切分），算「其他兩條的效果 − 正確率最低那條的效果」。
   - 兩者都報用到的（菜單、供體、切分）比例。
6. 模擬這一側（16 個區塊，子集一，規則 C）：
   - 確認用的菜單上的 D1：算法同 RQ3-GK 判定二，區塊值 = 200 次切分與 187 份菜單的平均。
   - 落單的 path 的 π ÷ 相像那一對的 π 的平均。π 在評分半上算，落單的 path 依第 7 節的算法在選擇半決定。分子、分母各自先對切分、菜單、16 個區塊平均，再相除。
   - 比值在全部 187 份與「明顯落單」組各報一次。
7. 每份菜單的落單程度（第 4 節）對上該菜單的 E2：
   - 菜單的 E2 = 10 × (相像那一對的分子總和 ÷ 分母總和 − 落單那條的分子總和 ÷ 分母總和)，總和的範圍是 8 個區塊、2 個供體、所有可用的切分。
   - 報 187 份菜單的 Spearman 相關（平手用平均排名）。
8. 判定一、判定二在規則 A 下的值：分子用規則 A 的得分，p\* 用規則 A 的 gain，落單的 path 不變（它只看答案）。
9. 舊的 30 份菜單（K3-01 到 K3-30）當作對照：

   - 報 30 份全部的 E1，以及各組的 E2。
10. 不除以分母的版本（判定一的兩群）：
    - 投票實際多幾個百分點 = 100 × 分子總和 ÷ 替換數。
    - 同時報那條 path 實際進步幾個百分點 = 100 × 分母總和 ÷ 替換數。
