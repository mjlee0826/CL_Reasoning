## 3. 聚合方式

- 優先順序：EN、ES、JA、P1、P2、R、RU、S1、S2、W1、W2、ZH，即 RQ1-K 的 `pathKey`。菜單裡沒有的 path 直接跳過。
- 子集內每條 path 都有答案，所以不會出現「沒答案的 path 不投票」的情況。
- V（等權多數決）：用 `Analysis.menuVote.vote`，與 RQ1-K、RQ3 相同。參與判定。
- 加權投票（WV 與 DS 共用）：
  - 每個答案的分數 = 給出這個答案的 path 的權重總和。分數最高的答案勝出。
  - 分數差在 1e-9 以內視為平手。平手時依優先順序找第一條答案落在平手答案中的 path，取它的答案，與 `vote` 相同。
  - 權重為 0 的 path 也參與這個順序。所有權重都是 0 時，全部答案平手，取優先順序第一條的答案。
- WV（依正確率加權的投票）：只報告。
  - p̂ = (選擇半答對題數 + 1) / (選擇半題數 + 2)；權重 = max(0, ln(p̂ / (1 − p̂)))。
  - 某條 path 被改進或被替換後，權重用改變後的選擇半答對題數重算。
- SB（選最強單一）：只報告。
  - 選擇半答對題數最多的那一條，平手依優先順序（`Analysis.probe.strongest`，即 RQ3 的 S_in）。在評分半上用它的答案。
  - path 被改進或替換後，用改變後的選擇半答對題數重新選。
- DS（不用標註的加權）：只報告，只算替換前與真實替換後兩種情況。
  - 只用評分半的題目，不用 gold。
  - 第 0 輪的共識 = V 的答案。
  - 第 k 輪（k = 1, …, 20）：每條 path 的可靠度 r = (評分半中與第 k−1 輪共識相同的題數 + 1) / (評分半題數 + 2)，權重 = max(0, ln(r / (1 − r)))。用加權投票得到第 k 輪的共識。
  - 第 k 輪的共識與第 k−1 輪逐題相同就停，取它。做滿 20 輪仍在變，就取第 20 輪的共識，記一次未收斂。
  - DS 的正確率 = 最後的共識在評分半的正確率。
- Oracle：菜單內至少一條答對的比例（評分半）。只報告。

## 4. 隨機改進模型

「把 path p 改進到正確率 a」：從 p 答錯的題目中等機率、不放回地抽題，把答案改成正確答案，直到正確率等於 a。
- 選擇半與評分半各自改到各自的目標。
- 只模擬往上改進，不模擬變差。
- 不實際抽樣，直接算期望值。

符號：對一次切分、一個半邊 h（1 = 選擇半，2 = 評分半），n_h = 題數，k_h = p 答對的題數，w_h = n_h − k_h，t_h = 要改對的題數（整數，0 ≤ t_h ≤ w_h）。

- 目標換成題數：
  - 「提高 Δ 個百分點」：t_h = ⌊Δ × n_h + 0.5⌋，即四捨五入到整數題。同一個半邊裡，每條 path 改對的題數相同。
  - 「改進到供體的正確率」：t_h = 供體那條 path 在該半的答對題數 − k_h。兩者是同一批題目，所以是整數。
  - 「改進到 100%」：t_h = w_h。
- 被改對的機率：f_h = t_h / w_h。w_h = 0 時 f_h = 0，因為沒有可改的題目。
- 聚合器的規則：
  - 由選擇半改進後的答對題數 k_1 + t_1 決定，與抽到哪幾題無關，所以是確定的。
  - WV：p 的權重用 p̂ = (k_1 + t_1 + 1) / (n_1 + 2) 重算，其他 path 的權重不變。
  - SB：p 的答對題數當作 k_1 + t_1，重新選。
  - V：沒有規則要定。
- 評分半的期望正確率：
  - G_i(原) = 用上述規則、p 維持原答案時，聚合在第 i 題是否答對。G_i(改) = p 改成正確答案時，聚合在第 i 題是否答對。
  - 期望正確率 = (1 / n_2) × [ Σ_{p 答對的題} G_i(原) + Σ_{p 答錯的題} ((1 − f_2) × G_i(原) + f_2 × G_i(改)) ]。
  - 「其餘題目不變」指 p 在這些題目上的答案不變；WV、SB 在這些題目上仍用改進後的規則。
  - SB 選到 p 時，期望正確率 = (k_2 + t_2) / n_2；選到別條時，就是那一條的正確率。
- π_p（只對 V）：在某個半邊，p 答錯的題目中，「把 p 改成正確答案後 V 由錯變對」的比例。w_h = 0 時無定義。
  - 把 p 改對不會讓 V 由對變錯，因為正確答案多一票、p 原本的答案少一票。
  - 所以 V 的期望增加量 = (t_h / n_h) × π_p。

## 5. 判定一：有沒有哪一條 path 特別值得改（16 個區塊，M12，V，子集一）

- 標準化的改進：把 path 的正確率提高 5 個百分點；不足 5 個百分點時提高到 100%。也就是 t_h = min(w_h, ⌊0.05 × n_h + 0.5⌋)。
- gain_h(p) = 100 × (改進後 V 的期望正確率 − 原本 V 的正確率)，在半邊 h 上算，單位 pp。
- 每次切分：
  - 在選擇半算 12 條的 gain_1，選最大的 p\*。
    - 比較時用有理數 t_1 × (p 答錯且改對後 V 由錯變對的題數) / w_1 精確比較，避免浮點誤差造成的假平手。
    - 平手依優先順序。
  - 在評分半算 D1 = gain_2(p\*) − 其餘 11 條 gain_2 的平均。
- 區塊值 = 200 次切分的平均。
- 正向 = 選擇半挑出來的 path，在評分半上的 gain 比其他 path 大。
- 事先寫下的讀法（論文會怎麼寫）：
  - 正向成立：path 的影響力不同，用一半題目就能挑出比較值得改的那一條。
  - 兩者相當：把任何一條 path 提高 5 個百分點，投票的增加量彼此相差不到 0.5pp。這是絕對量的說法；相對的差別看第 8 節 2 的兩個組成。
  - 反向成立：挑出來的反而較差，影響力的排名不穩定，只能當雜訊。
  - 無法判定：只列數字，不說有沒有差別。

## 6. 判定二：隨機模型預測得準真實的替換嗎（8 個弱模型區塊，M12，V，子集二）

- 每個替換 (h, g, p)、每次切分：
  - A_real = 真實替換後，V 在評分半的正確率。
  - A_sim = 隨機改進模型把 h 的 path p 改進到「供體那條 path 的實際正確率」時，V 在評分半的期望正確率。選擇半、評分半各自對到供體在該半的答對題數。
  - D2 = 100 × (A_real − A_sim)，單位 pp。
- 有效切分：供體那條 path 在選擇半與評分半的答對題數都嚴格多於宿主那條。不是有效切分的，該次切分不計。
- 排除比例 = 無效切分數 ÷ 200，逐替換報告。排除比例超過 20% 的替換不參與判定，另外列出。
- 區塊值（兩段平均）：
  - 先對每個替換，取它有效切分的 D2 平均。
  - 再對區塊內參與判定的替換（最多 24 個）取等權平均。
  - 若某個區塊沒有任何替換參與判定，就停下來回報，不算判定二。
- 正向 = 真實替換後的多數決比隨機模型的預測高。
- 事先寫下的讀法：
  - 反向成立（真實低於預測）：隨機模型高估；改對哪些題目，比正確率提高多少更重要。
  - 兩者相當：隨機模型可以當作估算真實改進效果的工具。
  - 正向成立（真實高於預測）：真實改進比隨機更常落在差一票的題目上，隨機模型低估。
  - 無法判定：只列數字。

## 7. 統計與判定

- 統計單位是區塊。跨區塊報平均、SE（= 標準差 / √區塊數）、95% t 區間（自由度 = 區塊數 − 1）、幾個區塊為正。
  - 判定一有 16 個區塊，判定二有 8 個。
  - 計算用 `Analysis.blockStats.summarize`，狀態用 `Analysis.blockStats.fourState`，與 RQ3 相同。
- 以下照 RQ3 判定標準檔（`result/analysis/rq3/rq3_criteria.md` §4）原文抄入：
  - 門檻：**0.5pp**（暫定值，確認本檔時一併確認）。
  - 狀態有四種，都是先對區塊取平均，再和門檻比：

## 8. 只報告的量（不參與判定）

除非另外註明，以下規則都適用：
- 替換的量都只用該替換的有效切分（第 6 節）。
- 排除比例超過 20% 的替換另外列出，不併入區塊的值。
- 跨區塊的摘要都用 `summarize`（平均、95% t 區間、為正的區塊數），只描述。

1. 逐區塊、逐 path 的量（M12，子集一，評分半，200 次切分平均）：
   - π_p、正確率、gain_2（第 5 節的 +5pp）。
   - π_p 無定義的切分不納入平均，報次數。
2. 判定一的選擇：
   - p\* 落在各條 path 的比例，逐區塊列出，並報 16 個區塊的平均。
   - 選擇半出現平手的切分比例。平手 = 最大的 gain_1 由兩條以上共有。
   - 逐區塊列出 gain_2(p\*) 與其餘各條 gain_2 的平均（200 次切分平均），並報 16 個區塊的平均。M3 菜單同樣列出。
3. 曲線資料（M12，子集一）：
   - 每個區塊、每條 path，隨機改進模型下 V、WV、SB 在評分半的期望正確率，以及改進後那條 path 在評分半的正確率（200 次切分平均）。
   - 目標：原本（+0，曲線的起點）、+2、+5、+10、+20 個百分點，以及 100%。
   - +Δ 的 t_h = ⌊Δ × n_h + 0.5⌋，不設上限。
   - 只要有一次切分的任一半 t_h > w_h（超過 100%），這個點就略過，記下有幾次切分不足。
4. 每個替換（子集二）：
   - 宿主與供體那條 path 的正確率（評分半）。
   - 修對的題數（宿主錯、供體對）與弄壞的題數（宿主對、供體錯），在整個子集二上數，不切分。
   - 「錯換成另一個錯答案」的題數（宿主錯、供體也錯，但兩者答案不同），和修對、弄壞一樣在整個子集二上數，不切分。
   - V、WV、SB、DS、Oracle 在替換前後的正確率（評分半），以及 DS 未收斂的切分數。
   - V、WV、SB 的 A_sim：第 6 節的隨機模型；WV、SB 的規則依第 4 節。
5. 「只修不壞」版本（V）：
   - A_fix = 只把「宿主錯、供體對」的題目換成供體的答案、其餘保留宿主的答案時，V 在評分半的正確率。
   - A_fix,sim = 隨機改對相同題數時，V 在評分半的期望正確率。每一半的 t_h = 該半修對的題數。
   - D5 = 100 × (A_fix − A_fix,sim)。有效切分、20% 規則與兩段平均都同判定二。
   - 報 8 個區塊的平均、95% t 區間與為正的區塊數。
6. 轉換率（評分半，V）：
   - 真實：有效切分上「替換後 V 增加的正確率」的平均 ÷ 「那條 path 增加的正確率」的平均。
   - 隨機模型：分子換成 A_sim − 替換前 V 的正確率，分母相同。
   - 逐替換的比值照列。
   - 區塊值 = 區塊內參與判定的替換，分子的總和 ÷ 分母的總和（真實與隨機模型各一個）。報 8 個區塊的平均與 95% t 區間。
7. 預測與實際的排序（V）：
   - 預測增加量（選擇半算出）：隨機模型把 h 的 path p 改進到供體在選擇半的答對題數時，V 在選擇半的期望增加量，即正確率增加量 × 選擇半的 π_p。
   - 實際增加量（評分半）：A_real − 替換前 V 的正確率。
   - 每次切分，對區塊內參與判定、且該次切分有效的替換，算兩者的 Spearman 相關。
     - 平手用平均排名。
     - 少於 3 個替換，或任一邊全部相同時，該次切分無定義。
   - 區塊值 = 有定義的切分的平均。報 8 個區塊的值、它們的平均，以及無定義的切分數。
8. 領先幅度：
   - 領先幅度 = 替換後那條 path 在選擇半的正確率 − 其餘 11 條在選擇半的最高正確率（pp）。
   - 對上評分半的 V − SB 與 WV − SB（替換後）。
   - 逐個替換存成 CSV，值為有效切分的平均。
   - 區塊內的 Spearman 相關照第 7 項的做法（逐切分算再平均），V − SB、WV − SB 各一個。
9. M3L、M3S、M3P（只用 V）：
   - 判定一的量：16 個區塊（子集一）的 D1，「其餘 11 條」改為菜單內其餘 2 條。逐 path 的 π_p、正確率、gain_2 與 p\* 比例也寫進 cells CSV。
   - 判定二的量：8 個弱模型區塊（子集二）的 D2，每個區塊 3 條 path × 2 個供體 = 6 個替換。有效切分、20% 規則與兩段平均同第 6 節。
   - 各報平均、SE、95% t 區間、為正的區塊數，不套四種狀態。

## 9. 開跑前的檢查

依序做，任何一項不過就停下來回報，不寫輸出。第 2 節的題目 id 與 gold 核對不符，也一樣停。

1. 重現 RQ3：用這次的程式在子集一上算 M12 的 V（A_V）、SB（S_in）與差距 Excess = A_V − SB。
   - 逐區塊和 `result/analysis/rq3/rq3_blocks.csv` M12 那一列的 `A_V`、`S_in`、`excess_in_pp` 比，差都要 ≤ 1e-9；題數要等於 `n_subset`。
   - 16 個區塊的摘要四捨五入到小數兩位後要是：多數決 84.67%、最強單一 path 84.37%、差距 +0.30pp（−0.63 到 +1.23）、12 / 16 為正。
2. 期望值的算法：qwen × truthfulqa、子集一、path L:zh（ZH）、提高 5 個百分點（第 5 節的 t_h）。
   - 用 `numpy.random.default_rng(0)` 實際抽 2,000 次。每一次：
     - 依序對 200 次切分，先選擇半、後評分半，從 ZH 答錯的題目中不放回抽 t_h 題，改成正確答案。
     - 再用一般的聚合函式（不經期望值的算法），以改過的選擇半定 WV 的權重與 SB 的選擇，在改過的評分半上算 V、WV、SB 的正確率。
     - 這一次的值 = 200 次切分的平均。
   - V、WV、SB 各自要滿足：|2,000 次的平均 − 期望值| ≤ 3 × 蒙地卡羅標準誤，標準誤 = 2,000 個值的標準差 / √2000。
   - 標準誤為 0 時（例如 SB 的結果與抽到哪幾題無關），差要 ≤ 1e-9。
3. 把一條 path 換成它自己：對 16 個區塊、M12 的 12 條 path，令供體 = 宿主，跑替換的程式。
   - 每次切分，V、WV、SB、DS、Oracle 替換前後的正確率差都 ≤ 1e-12。
   - 修對與弄壞的題數都是 0；子集二等於子集一。
   - 隨機改進模型在 t_h = 0 時，V、WV、SB 的期望正確率等於原本的正確率，差 ≤ 1e-12。
4. 列出 16 個 (h, g, 資料集) 的子集二保留比例，低於 85% 的特別標出。這一項只列出，不因比例低而停。
