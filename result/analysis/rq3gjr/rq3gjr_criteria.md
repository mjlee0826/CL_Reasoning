## 3. 模型：條件式 logit（從 K 個候選裡選一個）

- 每次呼叫是一組，K 個候選是選項，被選的那個記 1。
  - 候選 j 的分數 = 各因素乘上係數的總和。
  - 被選的機率 = exp(分數) ÷ 全部候選 exp(分數) 的總和。
  - 不加截距、不做正則化。用 statsmodels 的 ConditionalLogit 或等價的最大概似。
- 候選層級的因素：
  - correct：這份的答案等於 gold（1 / 0）。
  - support：其他候選中和它同答案的份數 ÷ (K − 1)。
  - first、last：排在第一個、最後一個（各 1 / 0；中間是基準）。
  - donor：這份是供體（強模型）寫的（1 / 0）。
  - trans：path 是 JA、ZH、RU、ES（1 / 0）。
  - short：path 是 R（1 / 0）。
  - loglen：這份 `raw_text` 的 tokens 數取自然對數。用 tiktoken 的 `o200k_base`，只當長度的量尺。第零階段確認可用，沒有改用字元數。
- 模型系列（因素逐步加入）：
  - M0：correct、support、first、last
  - M1：M0 + donor
  - M2：M1 + trans、short
  - M3：M2 + loglen ← **主要模型，判定用它**
  - M4：M3 + correct×donor、correct×trans、correct×short（只報告）
  - M5a：M3 + pathacc（沒有交互作用項；只報告，只用在第 7 節 3 的逐區塊配適）
  - M5b：M4 + pathacc（只報告，只用在第 7 節 3 的逐區塊配適）
    - pathacc：這份候選所屬的（模型、path）在該資料集子集一全部題目上的正確率（0 到 1）。
    - 裁判看不到這個數字；它只當「這條 path 的推理平均有多好」的代理。
    - 【補充，待確認】子集一用寫這份候選的模型自己的子集一（該模型 12 條 path 都有答案的題目）。供體寫的候選用供體的子集一。
- 一筆（版本、題目）預測的正確機率 = Σ 候選 j 被選的機率 × correct_j。
- 一個版本預測的正確率 =（不用呼叫的題目的已知對錯 + 要呼叫的題目的預測機率）的平均。
- 【補充，待確認】實作與適用範圍：
  - **最大概似的算法**：自己寫的牛頓法，用精確的梯度與 Hessian（等價的最大概似）。停止條件是每個係數的步長 < 1e-10，最多 50 步；沒有收斂就停下來回報。
    - 理由：statsmodels 的 ConditionalLogit 逐組計算，在約 35 萬組的資料上太慢。
    - 第 10 節 6 會在小樣本上和 statsmodels 的 ConditionalLogit 比對係數。
  - **K = 3 的 support**：要呼叫的題目三條答案不完全相同，所以 support 只會是 0 或 0.5。第零階段：0 佔 40.8%、0.5 佔 59.2%、1 是 0%。
  - **K = 2**：
    - first 與 last 每個候選必有一個是 1，只有兩者係數的差有作用；
    - support 一律是 0（兩條相同就不呼叫）；
    - 三個配對裡沒有 R，所以 short 一律是 0。
  - **K = 12**：沒有供體，donor 一律是 0。

## 6. 兩項判定（都用 M3、留一個資料集；門檻 0.5pp）

四種狀態，照 RQ3-GJ 判定標準檔 §2.1（即 RQ3-GS §8、RQ3-GK §8、RQ3-G §7）的原文抄入：
- 門檻：**0.5pp**（暫定值，確認本檔時一併確認）。
- 狀態有四種，都是先對區塊取平均，再和門檻比：
  - 正向成立：平均 ≥ +0.5pp，且 95% 區間不含 0。
  - 反向成立：平均 ≤ −0.5pp，且 95% 區間不含 0。
  - 兩者相當：整個 95% 區間落在 [−0.5, +0.5] 之內。
  - 無法判定：其他情況。

### 6.1 判定一：換到沒看過的資料集，M3 估得準嗎

- D_P = 替換後 Judge 的實際正確率 − M3 預測的正確率（pp）。區塊值 = 對 200 次切分 × 區塊內所有參與的替換取平均。
- 讀法：
  - 兩者相當：誤差在 0.5pp 內；放進這些因素後，預測可以用在沒看過的資料集（仍需要標準答案）。
  - 正向成立：仍然低估。
  - 反向成立：高估。
  - 無法判定：只列數字。

### 6.2 判定二：多放的因素讓預測實質變準嗎

- G = T_new 每個替換的平均絕對誤差 − M3 每個替換的平均絕對誤差（pp）。
  - 每個替換的平均絕對誤差 = 對 200 次切分平均 |D_P|，算法同 RQ3-GJ 第 8 節 7(b)。
  - 區塊值 = 區塊內所有參與的替換的平均。
  - 正向 = M3 的誤差比較小。
- 讀法：
  - 正向成立：誰寫的、文字類型、長度讓預測實質變準。
  - 兩者相當：多放這些因素沒有實質幫助；比例表不準的原因不在這裡。
  - 反向成立：多放因素反而變差。
  - 無法判定：只列數字。
- 事先寫下的限制：
  - (a) 測試的資料集沒看過，但菜單、path、模型都看過。
  - (b) 這批紀錄已經被用來形成「強模型的候選較常被選」等觀察；判定檢驗的是預測準不準，不是那些觀察本身。
  - (c) 預測需要知道每份候選對不對。

只有這兩項參與判定，其餘都只報告，不套四種狀態（第 7 節 4(a) 的讀法只用區間）。

### A.4 估計的計算時間

- 做法：用隨機產生的假資料（不碰真實紀錄），以第 3 節的牛頓法配適條件式 logit 計時。
- 70 萬組 × 3 個候選：8 個因素 3.5 秒，11 個因素 5.1 秒，6 步收斂。
- 這次每次配適約 25 萬到 50 萬組；配適約 128 次：
  - 留一個資料集 2 × 4 × 5 個模型，加上字元數的 M3；
  - 逐區塊 M3、M4、M5a、M5b 各 8 次；
  - 留一組菜單 8 次；
  - 同一資料集內 2 × 20 次。
- 合計約 10 分鐘。加上特徵、預測與 200 次切分的評分，估計 20 到 30 分鐘。
